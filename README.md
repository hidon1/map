# חדשות עכשיו — הגדרת ה-API

הפרויקט בנוי לעבוד על Cloudflare Pages.

## מבנה הפרויקט

- `index.html` — אתר החדשות עצמו: עיצוב, מבזקים, כתבות, קטגוריות ורענון כל 5 דקות.
- `functions/api/news.js` — פונקציית השרת. היא זמינה באתר בכתובת `/api/news`, פונה ל-OpenAI, משתמשת בחיפוש אינטרנט ומחזירה JSON של כתבות.

## איפה שמים את מפתח OpenAI

לא מכניסים אותו לקוד.

ב-Cloudflare:

1. פתח Cloudflare Dashboard.
2. עבור ל-Workers & Pages.
3. פתח את פרויקט ה-Pages שמחובר ל-`hidon1/map`.
4. עבור ל-Settings > Variables and Secrets.
5. הוסף Secret בשם:

   `OPENAI_API_KEY`

6. הדבק שם את מפתח OpenAI שלך.
7. שמור ובצע Deploy מחדש.

אפשר להוסיף גם משתנה רגיל בשם:

`OPENAI_MODEL`

אם לא מגדירים אותו, הקוד משתמש כברירת מחדל ב-`gpt-5.6`.

## איך המערכת עובדת

הדפדפן קורא ל-`/api/news`.

הפונקציה `functions/api/news.js`:

- בודקת אם יש תשובה שמורה ב-Cache.
- אם יש Cache בן פחות מ-5 דקות, מחזירה אותו בלי קריאת OpenAI נוספת.
- אחרת פונה ל-OpenAI Responses API.
- מבקשת חדשות ממקורות ישראליים כלליים וחרדיים.
- מחזירה עד 30 כתבות במבנה JSON קבוע.
- שומרת את התוצאה ל-5 דקות.

כך מפתח ה-API נשאר בצד השרת ואינו נשלח לדפדפן.

## חשוב

GitHub Pages לבדו אינו מריץ את תיקיית `functions`.
כדי ש-`/api/news` יעבוד יש לפרוס את המאגר ב-Cloudflare Pages או פלטפורמה תואמת לפונקציות שרת.
